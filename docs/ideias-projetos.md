# Próximas ideias de projetos

Nomes de trabalho e propostas futuras. Nenhum novo repositório ou implementação foi criado para estas ideias.

| Nome | Ideia |
| --- | --- |
| **QueryLens** | Laboratório de diagnóstico e análise de consultas SQL, com exemplos reproduzíveis e dados sintéticos. |
| **PulseOps** | Registro de incidentes, investigação de causa e acompanhamento de ações de sustentação. |
| **TraceLedger** | API de trilhas de auditoria para acompanhar alterações e eventos de uma aplicação. |
| **RestoreProof** | Laboratório para registrar e conferir exercícios de backup e restauração. |
| **BridgeLab** | Ambiente de simulação de integrações entre APIs, com contratos e mensagens de exemplo. |
| **ClarityDesk** | Painel de relatórios com filtros, exportação e atenção à leitura e navegação por teclado. |

## Ordem sugerida

1. **QueryLens:** relaciona o portfólio à experiência com Oracle SQL/PLSQL.
2. **PulseOps:** mostra o raciocínio de sustentação N2/N3 em um produto próprio.
3. **TraceLedger:** conecta desenvolvimento back-end, auditoria e segurança.
4. **RestoreProof, BridgeLab e ClarityDesk:** ampliam o conjunto conforme o objetivo profissional escolhido.

A proposta é aprofundar problemas reais em projetos demonstráveis, usando dados sintéticos e exemplos próprios. Os nomes ainda não passaram por pesquisa de disponibilidade de marca ou domínio.
